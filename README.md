# 🌍 JiggyConvert  

> ⚡ Fast, beautiful currency conversion for web & mobile 

---

## ✨ Overview  
GlideConvert is a modern, responsive currency converter built with HTML, CSS, and Node.js.  
It allows users to quickly convert between currencies using live exchange rates.  
The UI is designed with glassmorphism and mobile-first responsiveness, making it smooth on any device. 

---


## 🚀 Features  
- 🌐 Real-time currency conversion  
- 📱 Mobile-first, responsive design  
- 🎨 Glassmorphism-inspired interface  
- 🔄 Swap currencies instantly  
- 🕑 Keeps a short conversion history  
- ⚡ Works seamlessly on web and mobile  

---

## 🛠️ Tech Stack  
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js + Express  
- API: [open.er-api.com](https://open.er-api.com/)  

---

## 📦 Installation  

Clone the repository:  
```bash
git clone https://github.com/yourusername/glideconvert.git
cd glideconvert
install dependecies: npm install
run server: npm start
app will be available at: http://localhost:3000
```

---
📖 Usage
 1. Enter the amount you want to convert.
 2. Select From and To currencies.
 3. Click Convert to see results instantly.
 4. Use Swap button to flip currencies.
 5. View your recent conversions below the result box.
